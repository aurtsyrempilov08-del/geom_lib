# Geometric Lib

## Общее описание
Здесь представлена библиотека на Python для рассчета площади и периметра геометрических фигур.

В проекте есть 4 файла:
- circle.py - круг
- square.py - квадрат
- rectangle.py - прямоугольник
- triangle.py - треугольник

## Описание функций и примеры вызова

### 1. circle.py
- area(r) - возвращает площадь круга радиуса r.
Пример:
circle.area(5) вернет 78.53981633974483

- perimeter(r) - возвращает длину окружности круга радиуса r.
Пример:
circle.perimeter(5) вернет 31.41592653589793

### 2. square.py
- area(a) - возвращает площадь квадрата со стороной a.
Пример:
square.area(4) вернет 16

- perimeter(a) - возвращает периметр квадрата со стороной a.
Пример:
square.perimeter(4) вернет 16

### 3. rectangle.py
- area(a, b) - возвращает площадь прямоугольника со сторонами a и b.
Пример:
rectangle.area(3, 5) вернет 15

- perimeter(a, b) - возвращает периметр прямоугольника со сторонами a и b.
Пример:
rectangle.perimeter(3, 5) вернет 16

### 4. triangle.py
- area(a, h) - возвращает площадь треугольника со стороной a и высотой h.
Пример:
triangle.area(4, 5) вернет 10.0

- perimeter(a, b, c) - возвращает периметр треугольника со сторонами a, b, c.
Пример:
triangle.perimeter(3, 4, 5) вернет 12
